# パッと見問題 ～この漫画全何巻？～

漫画の表紙を見て、5秒以内に「全何巻か」を当てるクイズです。
当たったら踊ります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（これ1枚で動きます） |
| `questions.json` | 問題データ（作品名・巻数・出典など） |
| `images/` | 表紙や全巻写真を置くフォルダ（任意） |
| `favicon.svg` | ブラウザのタブに出るアイコン |
| `.nojekyll` | GitHub Pagesに余計な変換をさせないための空ファイル |

## GitHub Pagesで公開する手順

1. このフォルダの中身をリポジトリの直下に置いて、push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** で「Deploy from a branch」を選び、ブランチ（例：`main`）とフォルダ（`/ (root)`）を指定して保存します。
4. 数分待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります。

### 注意

- プライベートリポジトリからPagesを公開するには、GitHub Pro / Team / Enterprise Cloud のいずれかが必要です（無料プランは不可）。
- リポジトリを非公開にしていても、**公開されたページ自体は誰でも見られます**（ページを非公開にできるのは Enterprise Cloud のみ）。

## 手元で動作確認する

`index.html` をダブルクリックで開くと、問題データを読み込めません（ブラウザの制限）。
このフォルダで次のコマンドを実行して、`http://localhost:8000` を開いてください。

```
python3 -m http.server 8000
```

## 問題を追加・修正する

`questions.json` の `questions` の中に、次の形で1問ずつ書きます。
GitHub上でファイルを直接編集してコミットするだけで反映されます。

```json
{
  "id": "q36",
  "title": "作品名",
  "vols": 34,
  "edition": "数えた版・レーベル（例：ジャンプ・コミックス）",
  "note": "補足（例：完全版は数えない）",
  "sourceName": "出典の名前",
  "sourceUrl": "https://出典のURL",
  "noteSourceName": "補足の出典の名前",
  "noteSourceUrl": "https://補足の出典のURL",
  "checkedAt": "2026-10-15",
  "lines": "表紙イラストの改行/位置",
  "color": "#3b3f8f"
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `title` | ○ | 作品名 |
| `vols` | ○ | 正解の巻数（数字） |
| `sourceUrl` / `sourceName` | 推奨 | 巻数の出典。正解発表でリンク表示されます |
| `checkedAt` | 推奨 | 出典を確認した日（`YYYY-MM-DD`） |
| `edition` | 任意 | どの版で数えたか |
| `note` | 任意 | 別の版・外伝・続編の扱いなど |
| `noteSourceUrl` / `noteSourceName` | 任意 | 補足の出典 |
| `lines` | 任意 | 表紙イラストの作品名の改行位置を `/` で区切る。空なら自動 |
| `color` | 任意 | 表紙イラストの色（`#rrggbb`）。空なら自動 |
| `cover` / `shelf` | 任意 | `images/` に置いた写真のパス（例：`images/akira-cover.jpg`）。なければイラストで表示 |

- 書き方を間違えると、その問題だけ読み飛ばされます（`title` が空、`vols` が数字でない など）。
- JSONは最後の項目の後ろにカンマを付けると全体が読めなくなるので注意してください。
- 連載中の作品は巻数が変わるので、完結済みの作品がおすすめです。完結済みでも新刊が出ることがあります（こち亀は202巻・203巻が出ました）。

## 表紙写真について

公開ページは誰でも見られるため、実際の表紙写真は使わず、イラスト表示のままにしておくのが無難です。
表紙を使う場合は、出版社ごとの書影の利用ルールを確認してください。
